XGBoost and Temporal Feature Engineering for Precise CO Emission Prediction in Dhaka City

Explainable AI

Explainable AI for Forecasting Earthquake-Induced Psychological Trauma

Developed an interpretable ML framework using psychological survey data from 500 respondents to predict earthquake-induced trauma risk. Built a stacked hybrid model combining Random Forest, Logistic Regression, and XGBoost, achieving 67.2% accuracy and 88.2% recall. Used SHAP and permutation importance to identify key psychological predictors of trauma.

🧬
Clinical ML

Leakage-Controlled Machine Learning and TriTreeStack Ensemble for Ovarian Tumor Classification

Developed a leakage-controlled clinical machine learning framework using Random Forest, XGBoost, CatBoost, and a proposed TriTreeStack ensemble to distinguish benign and malignant ovarian tumors, with nested cross-validation, calibration analysis, bootstrap uncertainty estimation, and SHAP-based explainability.
